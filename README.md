

# Todo App

A simple Todo application built as part of Chosun University's extracurricular program, **"Claude-based AI Agent Development Special Lecture." , Day 1**

## Overview

This project was created to practice AI-assisted development using Claude Code.  
The goal of this project is to understand how an AI agent can support the process of building, improving, and managing a small web application.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Manage a simple Todo list
- Practice project-based development with Claude Code

## Purpose

This repository is part of my development practice portfolio.  
Through this project, I practiced using Claude Code to explore code structure, generate implementation ideas, and improve development workflow.
